# جرّبها

تطبيق Flutter عربي للتعلّم بالممارسة عبر مسارات قصيرة، تحديات قابلة للإنجاز، مؤشرات تقدّم حقيقية، ومدرّب ذكي لا يعمل قبل موافقة المستخدم الصريحة.

## التشغيل

1. ثبّت Flutter المستقر وXcode الحالي.
2. انسخ `.env.example` إلى `.env` وأدخل قيم التطوير الحقيقية. لا تُضمَّن `.env` في التطبيق.
3. حدّث القيم العامة في `lib/app/app_config.dart` عند تغيير إعدادات الإصدار.
4. نفّذ:

```sh
flutter pub get
flutter test
flutter analyze
flutter build ios --release --no-codesign
```

## الذكاء الاصطناعي

التطبيق لا يحتوي مفتاح Groq. يرسل محادثة محدودة إلى `GROQ_PROXY_URL` بعد الموافقة فقط. مصدر وكيل قابل للنشر موجود في `server/groq-proxy`، ومفتاح `GROQ_API_KEY` يبقى في بيئة الخادم.

## قبل App Store Connect

- استبدل معرّف الحزمة `com.yourcompany.tryit` بمعرّف حسابك النهائي إذا لزم.
- انشر وكيل Groq، ثم مرّر رابطه العام عند البناء:

  `flutter run --dart-define=GROQ_PROXY_URL=https://YOUR-WORKER.workers.dev`

  لا تمرّر `GROQ_API_KEY` إلى Flutter؛ يبقى المفتاح سرّاً في Cloudflare Worker.
- استبدل روابط الخصوصية والدعم التجريبية بصفحات عامة تطابق سلوك التطبيق.
- راجع ملصق الخصوصية: رسائل المدرّب هي محتوى مستخدم يُرسل لمعالجة وظيفة التطبيق، ولا توجد تحليلات أو إعلانات أو مشتريات في هذا الإصدار.
- اختر فريق التوقيع، اختبر على جهاز حقيقي، ثم أنشئ الأرشيف من Xcode.
